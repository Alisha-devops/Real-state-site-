# Adil Real Estate — Website

Responsive single-page website built with semantic HTML5, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Included
- Responsive layout and mobile navigation
- Property filters (All / For Sale / For Rent / Commercial)
- WhatsApp inquiry links on property cards
- Inquiry form that prepares a WhatsApp message
- Supplied brand and office images in `assets/`

## Before publishing
1. Replace any image that is only a collage with approved, high-resolution individual property/office photos.
2. Confirm that the Facebook, Zameen.com and YouTube profile destinations are the correct official pages.
3. Verify current inventory, review wording, rating and follower count with the business.
4. Add a direct Google Business Profile review URL if available.
5. Update WhatsApp destination numbers if the preferred lead number changes.

The site uses the supplied business details and review copy; the website itself does not independently verify those claims.
